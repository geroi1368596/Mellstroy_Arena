# Mellstroy_Arena - Minimal 2D Arena Prototype

This repository contains a minimal Unity-ready prototype for a 2D arena with two characters (LaserGay and Boxer) that fly around, bounce from walls, and fight on contact. The project contains scripts and instructions so you can drop them into a Unity project quickly.

What I pushed:
- Assets/Scripts/Fighter.cs
- Assets/Scripts/LaserGayFighter.cs
- Assets/Scripts/BoxerFighter.cs
- Assets/Scripts/LaserBeam2D.cs
- Assets/Scripts/FloatingHealthUI.cs
- Assets/Scripts/HUDSetup.cs
- Assets/Scripts/FightingGameManager.cs
- .gitignore
- README.md (this file)

How to use (quick):
1. Create a new Unity 2D project (2020.3 LTS or 2021.3 LTS recommended).
2. Copy the `Assets/Scripts` folder from this repo into your project's `Assets/` folder.
3. Create the scene as described in the README (Camera portrait, Canvas, two character prefabs, laser prefab). The scripts are documented and the README gives a step-by-step quick-start.
